# سامانه هوشمند پردازش و ممیزی گزارش‌های دست‌نویس کارخانه
## Multi-Agent Factory Report OCR & Auditing System (`comScanerDemo`)

سیستم هوشمند پردازش و داوری چند ایجنتی برای خوانش اسناد، فاکتورها و فرم‌های صنعتی دست‌نویس فارسی با معماری ۴ لایه و ممیزی ریاضی محاسبات انسانی روی کاغذ بر پایه **Google Gemini API**.

---

### 🌟 ویژگی‌های کلیدی (Key Features)

1. **معماری ۳ ایجنتی موازی (Multi-Agent Architecture):**
   - **Agent A (Extractor 1):** مدل `gemini-3.8-flash` (دمای ۰.۱) جهت بازخوانی کاراکتر به کاراکتر دست‌خط و علائم خط‌خوردگی.
   - **Agent B (Extractor 2):** مدل `gemini-3.8-flash` (دمای ۰.۴) جهت شبیه‌سازی دیدگاه مستقل دوم (Second Opinion) با تمرکز بر بافت جوهر و ارقام مبهم فارسی.
   - هر دو ایجنت به صورت موازی (`Task.WhenAll`) در کسری از ثانیه اجرا می‌شوند.
   - **Agent C (Judge AI / سرحسابرس هوشمند):** داوری تصویری دقیق و تطبیق خروجی دو ایجنت با استدلال فارسی، به همراه کنترل صحت منطق ریاضی (`تولید کل - ضایعات = خالص`) و تراز جمع ستون‌ها.
2. **رابط کاربری پیشرفته و مدرن (Persian RTL UI):**
   - طراحی صنعتی تیره با افکت‌های Glassmorphism و فونت استاندارد **Vazirmatn**.
   - استپر گرافیکی و متحرک خط لوله (Pipeline Stepper) با حالت‌های درخشان فعال.
   - پنل تصویر تعاملی با کنترل‌های بزرگ‌نمایی (Zoom)، کوچک‌نمایی و تمام‌صفحه.
   - گالری برگه‌های نمونه کارخانه‌ای آماده تست.
3. **ممیزی خودکار خطاها و اختلافات:**
   - کارت‌های هشدار امبر برای مغایرت‌های خوانش ایجنت‌ها (`differencesFound`) با چرایی داور هوشمند.
   - کارت‌های هشدار رز برای خطاهای محاسباتی سرپرست روی برگه فیزیکی (`mathErrorsOnPaper`).
   - جدول نهایی تایید شده با قابلیت ویرایش سلولی و نشانگرهای خط‌خوردگی.
4. **خروجی و یکپارچگی:**
   - خروجی اکسل/CSV سازگار با حروف فارسی (UTF-8 BOM).
   - صدور فاکتور و ثبت سند در سیستم‌های ERP (سپیدار / راهکاران سیستم / SAP).
   - حالت پیش‌نمایش آفلاین (Mock Demo) بدون نیاز به اینترنت در جلسات ارائه.

### 🚀 نحوه راه‌اندازی (Quick Start)

#### پیش‌نیازها:
- [.NET 8.0 SDK](https://dotnet.microsoft.com/) یا بالاتر
- [Node.js v18+](https://nodejs.org/)

#### ۱. راه‌اندازی بک‌اند (ASP.NET Core Minimal API):
```bash
cd backend
dotnet restore
dotnet run --urls "http://localhost:5279"
```

#### ۲. راه‌اندازی فرانت‌اند (React + Vite + Tailwind):
```bash
cd frontend
npm install
npm run dev
```
سپس در مرورگر خود آدرس `http://localhost:3000` را باز کنید.

### 🔑 تنظیم کلید Google Gemini API
می‌توانید کلید رایگان خود را از [Google AI Studio](https://aistudio.google.com/app/apikey) دریافت نموده و به یکی از روش‌های زیر اعمال کنید:
1. در بالای رابط کاربری دکمه **«تنظیم Gemini API Key»** را بزنید و کلید را ذخیره نمایید.
2. یا در فایل `backend/appsettings.local.json`:
```json
{
  "Gemini": {
    "ApiKey": "YOUR_GEMINI_API_KEY"
  }
}
```
3. یا به عنوان متغیر محیطی سیستم: `GEMINI_API_KEY=YOUR_KEY`
